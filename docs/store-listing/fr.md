# ExportAI Chrome Web Store Listing

## Locale

Français (`fr`)

## Version

1.0.0

## Store Title

ExportAI

## Short Description

Exportez vos conversations ChatGPT en PDF, Markdown et JSON.

## Detailed Description

### Intro

ExportAI vous aide à exporter vos conversations ChatGPT en PDF, Markdown et JSON directement depuis votre navigateur.

### Export Formats

- PDF pour la lecture, l'impression et l'archivage
- Markdown pour la documentation et la modification
- JSON pour la sauvegarde structurée et le traitement ultérieur

### Supported Platform

ExportAI prend en charge :

- ChatGPT

La disponibilité et l'exhaustivité peuvent dépendre de la structure actuelle de la page et du contenu de la conversation.

### Why ExportAI

Conservez vos conversations ChatGPT utiles au-delà de la page du navigateur. ExportAI vous aide à archiver vos recherches, créer de la documentation et enregistrer des données structurées, tout en préservant la structure des messages lorsqu'elle est disponible.

Son flux local-first garde le processus d'exportation au plus près du navigateur. L'extension ne nécessite pas de compte pour ce flux.

### How It Works

1. Ouvrez une conversation ChatGPT.
2. Ouvrez ExportAI depuis la barre d'outils Chrome.
3. Choisissez PDF, Markdown ou JSON.
4. Affichez un aperçu lorsque disponible, puis exportez ou téléchargez le fichier.

### Privacy / Local-first

ExportAI est conçue comme un flux de travail local-first dans le navigateur. Elle utilise la permission Chrome `activeTab` pour travailler avec l'onglet actuel au lancement d'une exportation. Cette description ne formule pas de promesse de confidentialité plus large que ce que l'extension et ses informations de confidentialité publiées permettent d'établir. Consultez les informations de confidentialité actuelles et les permissions indiquées dans le Chrome Web Store avant utilisation.

### Known Scope

ExportAI se concentre sur l'exportation et l'archivage des conversations ChatGPT.
