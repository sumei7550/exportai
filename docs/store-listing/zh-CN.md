## Store Title

ExportAI：将 ChatGPT 对话保存为 PDF、Markdown 和 JSON

## Short Description

将 ChatGPT 对话导出为 PDF、Markdown 和 JSON。

## Detailed Description

### Intro

ExportAI 可帮助你直接在浏览器中将 ChatGPT 对话导出为 PDF、Markdown 和 JSON。

### Export Formats

- PDF：适合阅读、打印和归档
- Markdown：适合整理文档和继续编辑
- JSON：适合结构化备份和后续处理

### Supported Platform

ExportAI 支持：

- ChatGPT

实际可用范围和内容完整度可能取决于当前网页结构及对话内容。

### Why ExportAI

把有价值的 ChatGPT 对话保存在浏览器页面之外。ExportAI 可帮助你归档研究内容、制作文档并保存结构化对话数据；当网页提供相关信息时，会保留消息结构。

ExportAI 采用 local-first 的浏览器工作流，让导出过程尽量在浏览器一侧完成。使用此扩展工作流不需要注册账号。

### How It Works

1. 打开一段 ChatGPT 对话。
2. 从 Chrome 工具栏打开 ExportAI。
3. 选择 PDF、Markdown 或 JSON。
4. 在可用时查看预览，然后导出或下载文件。

### Privacy / Local-first

ExportAI 按照浏览器内的 local-first 工作流设计。开始导出时，扩展使用 Chrome 的 `activeTab` 权限处理当前标签页。本说明不会作出超出扩展实际行为及已发布隐私信息范围的隐私承诺。使用前请查看当前隐私信息和 Chrome Web Store 中列出的权限详情。

### Known Scope

ExportAI 专注于 ChatGPT 对话导出与归档。
