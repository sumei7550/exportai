# ExportAI Chrome Web Store Listing

## Locale

Português (Brasil) (`pt_BR`)

## Version

1.0.0

## Store Title

ExportAI

## Short Description

Exporte conversas do ChatGPT para PDF, Markdown e JSON.

## Detailed Description

### Intro

O ExportAI ajuda você a exportar conversas do ChatGPT para PDF, Markdown e JSON diretamente do navegador.

### Export Formats

- PDF para leitura, impressão e arquivamento
- Markdown para documentação e edição posterior
- JSON para backup estruturado e processamento posterior

### Supported Platform

O ExportAI oferece suporte a:

- ChatGPT

A disponibilidade e o nível de completude podem depender da estrutura atual da página e do conteúdo da conversa.

### Why ExportAI

Mantenha conversas úteis do ChatGPT além da página do navegador. O ExportAI ajuda a arquivar pesquisas, criar documentação e salvar dados estruturados, preservando a estrutura das mensagens quando disponível na página.

O fluxo local-first mantém a exportação próxima do navegador. A extensão não exige uma conta para esse fluxo.

### How It Works

1. Abra uma conversa do ChatGPT.
2. Abra o ExportAI na barra de ferramentas do Chrome.
3. Escolha PDF, Markdown ou JSON.
4. Visualize uma prévia quando disponível e exporte ou baixe o arquivo.

### Privacy / Local-first

O ExportAI foi projetado como um fluxo de trabalho local-first no navegador. A extensão usa a permissão `activeTab` do Chrome para trabalhar com a guia atual quando você inicia uma exportação. Esta descrição não faz promessas de privacidade mais amplas do que aquelas respaldadas pela extensão e pelas informações de privacidade publicadas. Consulte as informações atuais de privacidade e as permissões indicadas na Chrome Web Store antes de usar.

### Known Scope

O ExportAI se concentra na exportação e no arquivamento de conversas do ChatGPT.
