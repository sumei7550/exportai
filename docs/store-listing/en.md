## Locale

## Version

## Store Title

ExportAI

## Short Description

Export ChatGPT conversations to PDF, Markdown, and JSON.

## Detailed Description

### Intro

ExportAI helps you export ChatGPT conversations to PDF, Markdown, and JSON directly from your browser.

### Export Formats

- PDF for reading, printing, and archiving
- Markdown for documentation and further editing
- JSON for structured backup and further processing

### Supported Platform

ExportAI supports:

- ChatGPT

Availability and completeness can depend on the current page structure and the conversation content.

### Why ExportAI

Save useful ChatGPT conversations beyond the browser page. ExportAI helps you archive research, create documentation, and keep structured conversation data while preserving user and assistant message structure where available.

Its local-first workflow is intended to keep the export process close to your browser. ExportAI does not require an account for the extension workflow.

### How It Works

1. Open a ChatGPT conversation.
2. Open ExportAI from the Chrome toolbar.
3. Choose PDF, Markdown, or JSON.
4. Preview where available, then export or download the file.

### Privacy / Local-first

ExportAI is designed as a local-first browser workflow. The extension uses Chrome's `activeTab` permission to work with the current tab when you start an export. This listing does not make a broader promise about data handling than the extension and its published privacy information support. Review the current privacy information and Chrome Web Store permission details before use.

### Known Scope

ExportAI is focused on ChatGPT conversation export and archiving.
