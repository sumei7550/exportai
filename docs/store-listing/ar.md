## Short Description

## Detailed Description

### Intro

ExportAI إضافة Chrome تساعدك على تصدير محادثات ChatGPT إلى PDF وMarkdown وJSON مباشرةً من المتصفح.

### Export Formats

- PDF للقراءة والطباعة والأرشفة
- Markdown للتوثيق والتحرير لاحقًا
- JSON للنسخ الاحتياطي المنظم والمعالجة اللاحقة

### Supported Platform

تدعم ExportAI:

- ChatGPT

قد يختلف مدى التوفر والاكتمال حسب بنية الصفحة الحالية ومحتوى المحادثة.

### Why ExportAI

احتفظ بمحادثات ChatGPT المفيدة خارج صفحة المتصفح. تساعدك ExportAI على أرشفة الأبحاث وإنشاء التوثيق وحفظ بيانات المحادثة المنظمة، مع الحفاظ على بنية الرسائل عندما تكون متاحة في الصفحة.

يعتمد سير العمل على مبدأ local-first، بحيث تبقى عملية التصدير قريبة من المتصفح. لا تتطلب الإضافة حسابًا لاستخدام سير العمل هذا.

### How It Works

1. افتح محادثة ChatGPT.
2. افتح ExportAI من شريط أدوات Chrome.
3. اختر PDF أو Markdown أو JSON.
4. اعرض المعاينة عند توفرها، ثم صدّر الملف أو نزّله.

### Privacy / Local-first

صُممت ExportAI كسير عمل local-first داخل المتصفح. تستخدم الإضافة إذن Chrome المسمى `activeTab` للعمل مع علامة التبويب الحالية عند بدء التصدير. لا يقدّم هذا الوصف وعودًا أوسع بشأن الخصوصية مما تدعمه الإضافة ومعلومات الخصوصية المنشورة الخاصة بها. راجع معلومات الخصوصية الحالية وتفاصيل الأذونات في Chrome Web Store قبل الاستخدام.

### Known Scope

تركّز ExportAI على تصدير محادثات ChatGPT وأرشفتها.
