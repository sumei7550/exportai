## Short Description

## Detailed Description

### Intro

ExportAI 是一款 Chrome 瀏覽器擴充功能，協助你直接在瀏覽器中將 ChatGPT 對話匯出為 PDF、Markdown 和 JSON。

### Export Formats

- PDF：適合閱讀、列印與保存
- Markdown：適合製作文檔與後續編輯
- JSON：適合結構化備份與後續處理

### Supported Platform

ExportAI 支援：

- ChatGPT

實際可用範圍與內容完整度可能取決於目前的網頁結構及對話內容。

### Why ExportAI

讓實用的 ChatGPT 對話不只留在瀏覽器頁面中。ExportAI 可協助你保存研究內容、製作文檔並保留結構化對話資料；當網頁提供相關資訊時，也會保留訊息結構。

ExportAI 採用 local-first 的瀏覽器工作流程，讓匯出過程盡量在瀏覽器端完成。使用這項擴充功能不需要註冊帳號。

### How It Works

1. 開啟一段 ChatGPT 對話。
2. 從 Chrome 工具列開啟 ExportAI。
3. 選擇 PDF、Markdown 或 JSON。
4. 在可用時查看預覽，接著匯出或下載檔案。

### Privacy / Local-first

ExportAI 以瀏覽器內的 local-first 工作流程設計。開始匯出時，擴充功能使用 Chrome 的 `activeTab` 權限處理目前分頁。本說明不會作出超出擴充功能實際行為與已發布隱私資訊範圍的隱私承諾。使用前請查看目前的隱私資訊，以及 Chrome Web Store 列出的權限詳情。

### Known Scope

ExportAI 專注於 ChatGPT 對話匯出與保存。
