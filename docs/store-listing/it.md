# ExportAI Chrome Web Store Listing

## Locale

Italiano (`it`)

## Version

1.0.0

## Store Title

ExportAI: Salva le conversazioni di ChatGPT in PDF, Markdown e JSON

## Short Description

Esporta le conversazioni ChatGPT in PDF, Markdown e JSON.

## Detailed Description

### Intro

ExportAI ti aiuta a esportare le conversazioni ChatGPT in PDF, Markdown e JSON direttamente dal browser.

### Export Formats

- PDF per leggere, stampare e archiviare
- Markdown per documentazione e modifiche successive
- JSON per backup strutturati ed elaborazioni successive

### Supported Platform

ExportAI supporta:

- ChatGPT

La disponibilità e la completezza possono dipendere dalla struttura attuale della pagina e dal contenuto della conversazione.

### Why ExportAI

Conserva le conversazioni ChatGPT utili oltre la pagina del browser. ExportAI aiuta ad archiviare ricerche, creare documentazione e salvare dati strutturati, mantenendo la struttura dei messaggi quando disponibile.

Il flusso local-first mantiene l'esportazione vicino al browser. L'estensione non richiede un account per questo flusso.

### How It Works

1. Apri una conversazione ChatGPT.
2. Apri ExportAI dalla barra degli strumenti di Chrome.
3. Scegli PDF, Markdown o JSON.
4. Visualizza l'anteprima quando disponibile, quindi esporta o scarica il file.

### Privacy / Local-first

ExportAI è progettata come flusso di lavoro local-first nel browser. Usa il permesso Chrome `activeTab` per lavorare con la scheda attiva quando avvii un'esportazione. Questa descrizione non fa promesse sulla privacy più ampie di quelle supportate dall'estensione e dalle informazioni sulla privacy pubblicate. Prima dell'uso, consulta le informazioni aggiornate sulla privacy e i permessi indicati nel Chrome Web Store.

### Known Scope

ExportAI si concentra sull'esportazione e sull'archiviazione delle conversazioni ChatGPT.
