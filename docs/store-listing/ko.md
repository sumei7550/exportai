# ExportAI Chrome Web Store Listing

## Locale

한국어 (`ko`)

## Version

1.0.0

## Store Title

ExportAI

## Short Description

ChatGPT 대화를 PDF, Markdown, JSON으로 내보내세요.

## Detailed Description

### Intro

ExportAI는 브라우저에서 ChatGPT 대화를 PDF, Markdown, JSON으로 내보낼 수 있도록 돕는 Chrome 확장 프로그램입니다.

### Export Formats

- PDF: 읽기, 인쇄, 보관에 적합
- Markdown: 문서화와 후속 편집에 적합
- JSON: 구조화된 백업과 후처리에 적합

### Supported Platform

ExportAI는 다음 서비스를 지원합니다.

- ChatGPT

사용 가능 범위와 내용의 완전성은 현재 페이지 구조와 대화 내용에 따라 달라질 수 있습니다.

### Why ExportAI

유용한 ChatGPT 대화를 브라우저 페이지 밖에도 보관하세요. ExportAI를 사용하면 리서치를 아카이브하고 문서를 만들며 구조화된 대화 데이터를 저장할 수 있습니다. 페이지에서 정보를 제공하는 경우 메시지 구조도 유지합니다.

local-first 워크플로를 통해 내보내기 과정을 브라우저 가까이에서 처리하도록 설계했습니다. 이 확장 프로그램의 워크플로에는 계정이 필요하지 않습니다.

### How It Works

1. ChatGPT 대화를 엽니다.
2. Chrome 툴바에서 ExportAI를 엽니다.
3. PDF, Markdown 또는 JSON을 선택합니다.
4. 가능한 경우 미리보기를 확인한 뒤 파일을 내보내거나 다운로드합니다.

### Privacy / Local-first

ExportAI는 브라우저 안에서 사용하는 local-first 워크플로로 설계되었습니다. 내보내기를 시작할 때 현재 탭을 처리하기 위해 Chrome의 `activeTab` 권한을 사용합니다. 이 설명은 확장 프로그램의 실제 동작과 공개된 개인정보 보호 정보가 뒷받침하는 범위를 넘어서는 개인정보 보호를 약속하지 않습니다. 사용 전에 최신 개인정보 보호 정보와 Chrome Web Store의 권한 세부정보를 확인하세요.

### Known Scope

ExportAI는 ChatGPT 대화 내보내기와 아카이빙에 집중합니다.
