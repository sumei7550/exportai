## Store Title

ExportAI: Guarda conversaciones de ChatGPT en PDF, Markdown y JSON

## Short Description

Exporta conversaciones de ChatGPT a PDF, Markdown y JSON.

## Detailed Description

### Intro

ExportAI te ayuda a exportar conversaciones de ChatGPT a PDF, Markdown y JSON directamente desde el navegador.

### Export Formats

- PDF para leer, imprimir y archivar
- Markdown para documentación y edición posterior
- JSON para copias de seguridad estructuradas y procesamiento posterior

### Supported Platform

ExportAI admite:

- ChatGPT

La disponibilidad y el nivel de completitud pueden depender de la estructura de la página y del contenido de la conversación.

### Why ExportAI

Conserva conversaciones útiles de ChatGPT más allá de la página del navegador. ExportAI ayuda a archivar investigaciones, crear documentación y guardar datos estructurados, manteniendo la estructura de los mensajes cuando la página la proporciona.

Su flujo local-first mantiene el proceso de exportación cerca del navegador. La extensión no requiere una cuenta para este flujo.

### How It Works

1. Abre una conversación de ChatGPT.
2. Abre ExportAI desde la barra de herramientas de Chrome.
3. Elige PDF, Markdown o JSON.
4. Previsualiza cuando esté disponible y exporta o descarga el archivo.

### Privacy / Local-first

ExportAI está diseñada como un flujo de trabajo local-first en el navegador. Usa el permiso `activeTab` de Chrome para trabajar con la pestaña actual cuando inicias una exportación. Esta descripción no formula promesas de privacidad más amplias que las respaldadas por la extensión y su información de privacidad publicada. Consulta la información de privacidad vigente y los permisos de Chrome Web Store antes de usarla.

### Known Scope

ExportAI se centra en exportar y archivar conversaciones de ChatGPT.
