## Store Title

ExportAI: ChatGPTの会話をPDF、Markdown、JSONで保存

## Short Description

ChatGPT の会話を PDF、Markdown、JSON にエクスポート。

## Detailed Description

### Intro

ExportAI は、ブラウザから ChatGPT の会話を PDF、Markdown、JSON にエクスポートする Chrome 拡張機能です。

### Export Formats

- PDF：閲覧、印刷、アーカイブ向け
- Markdown：ドキュメント作成や編集向け
- JSON：構造化バックアップや後処理向け

### Supported Platform

ExportAI は以下のサービスに対応しています。

- ChatGPT

利用できる範囲や内容の完全性は、ページの構造や会話の内容によって異なる場合があります。

### Why ExportAI

役立つ ChatGPT の会話をブラウザのページ以外にも保存できます。研究内容のアーカイブ、ドキュメント作成、構造化された会話データの保存に利用できます。ページから取得できる場合は、メッセージ構造も保持します。

local-first のワークフローにより、エクスポート処理をブラウザの近くで行う設計です。この拡張機能のワークフローにアカウント登録は必要ありません。

### How It Works

1. ChatGPT の会話を開きます。
2. Chrome のツールバーから ExportAI を開きます。
3. PDF、Markdown、JSON のいずれかを選びます。
4. 利用できる場合はプレビューを確認し、エクスポートまたはダウンロードします。

### Privacy / Local-first

ExportAI は、ブラウザ内で動作する local-first のワークフローとして設計されています。エクスポート開始時には、現在のタブを扱うために Chrome の `activeTab` 権限を使用します。この説明では、拡張機能の実際の動作と公開済みのプライバシー情報で確認できる範囲を超える保証は行いません。利用前に、最新のプライバシー情報と Chrome Web Store の権限詳細を確認してください。

### Known Scope

ExportAI は ChatGPT の会話のエクスポートとアーカイブに特化しています。
