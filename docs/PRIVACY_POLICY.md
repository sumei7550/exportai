# ExportAI Privacy Policy

**Effective date:** August 30, 2026  
**Product:** ExportAI Chrome extension, version 1.0

ExportAI is a local-first browser extension for exporting readable AI conversations to files on the user's device. This Privacy Policy explains what ExportAI processes, what it does not collect, and what remains under the user's control.

> **Privacy contact:** `sumei7550@outlook.com`

## 1. Scope

This policy applies to the ExportAI Chrome extension and its published extension package. It does not govern ChatGPT, Claude, Gemini, Chrome, or any other website or service that the user opens in the browser. Those services have their own privacy policies and terms.

The current published extension package is configured to operate on ChatGPT pages. Platform support may change in a future release; this policy will be updated before a release materially changes data handling or permissions.

## 2. Data ExportAI processes

When the user explicitly starts an export, ExportAI may process the following information that is already readable in the current browser tab:

- conversation title, message roles, message order, and readable conversation content;
- structure needed for export, such as headings, lists, quotes, code, tables, formulas, links, and available image information;
- the current page URL or platform information when needed to identify the page and create export metadata;
- temporary in-memory data needed to parse the conversation, render a preview, and generate a PDF, Markdown, or JSON file.

ExportAI processes this information only to provide the requested export flow. It does not intentionally collect account passwords, cookies, authentication tokens, or hidden, deleted, or unloaded conversation data.

## 3. Data ExportAI does not collect

In the current release, ExportAI does not:

- require an ExportAI account or login;
- operate an ExportAI backend for conversation processing;
- sell, rent, or provide conversation content to advertisers or data brokers;
- use analytics, telemetry, advertising trackers, or error-reporting services;
- upload conversation text, prompts, answers, code, or images to an ExportAI server;
- use conversation content to train an AI model;
- create cloud storage, cross-device synchronization, or an online conversation library;
- intentionally read unrelated tabs or page content outside the active export context.

## 4. Where processing happens

Conversation parsing, normalization, preview generation, and file generation run in the browser. ExportAI creates the requested file locally and initiates a browser download to the location selected or managed by Chrome.

ExportAI does not retain a server-side copy of the conversation because the current release does not send conversation content to an ExportAI server. Temporary browser memory used during an export is released as the flow ends or the extension page is closed, subject to normal browser behavior.

The exported file is controlled by the user and may contain the conversation content selected for export. Chrome's download settings, backup tools, synchronization features, file indexing, and other software may process files after ExportAI creates them. Users should protect exported files according to their sensitivity.

## 5. Permissions

ExportAI requests the Chrome `activeTab` permission. It is used to communicate with and read the current tab when the user starts an export. The permission supports the core workflow of identifying a supported conversation, collecting readable content, and generating the requested local file.

ExportAI does not request a separate `downloads`, `storage`, or broad site-access permission in the current published manifest. Chrome may still display its own browser permission and extension-management information according to Chrome's behavior.

## 6. Third-party websites and content

ExportAI is not affiliated with OpenAI, ChatGPT, Anthropic, Claude, Google, Gemini, or any other platform named in the extension interface or documentation. ExportAI reads only content that the browser makes available on a supported page and does not bypass authentication, access private APIs, or recover content that is not present in the page.

The user remains responsible for confirming that they have the right to export, store, or share a conversation and any third-party material included in it. Exporting a conversation does not change the privacy terms, retention practices, or security of the original platform.

## 7. Retention and deletion

ExportAI does not maintain an online account or server-side conversation history. The user can delete locally generated files using the operating system or Chrome's normal file-management controls. If a future release introduces a new data flow, this policy will be updated before that flow is enabled and will explain the relevant retention and deletion choices.

## 8. Security

ExportAI is designed to minimize data movement and permissions. However, no browser extension, browser, local device, or file system can be guaranteed to be completely secure. Users should keep Chrome and their operating system updated, review extension permissions, and avoid exporting sensitive content to locations or services they do not control.

## 9. Children's privacy

ExportAI is a general-purpose browser extension and is not directed specifically to children. It does not knowingly collect personal information from children. Parents or guardians who believe that a child has provided personal information in connection with ExportAI may contact us using the address below.

## 10. Changes to this policy

We may update this policy when ExportAI's data practices, permissions, supported platforms, or applicable requirements change. The effective date at the top of this document will identify the latest version. Material changes will be communicated through the product's public listing or release information when appropriate.

## 11. Contact

For privacy questions or requests concerning ExportAI, contact:

**Email:** sumei7550@outlook.com

# ExportAI 隐私政策

**生效日期：** 2026 年 8 月 30 日  
**产品：** ExportAI Chrome 扩展，1.0 版本

ExportAI 是一款本地优先的浏览器扩展，用于将浏览器中可读取的 AI 对话导出为保存到用户设备的文件。本隐私政策说明 ExportAI 会处理哪些信息、不会收集哪些信息，以及哪些内容由用户自行控制。

> **隐私联系邮箱：** `sumei7550@outlook.com`

## 1. 适用范围

本政策适用于 ExportAI Chrome 扩展及其发布包，不适用于用户在浏览器中打开的 ChatGPT、Claude、Gemini、Chrome 或其他网站和服务。上述服务有各自的隐私政策和使用条款。

当前发布的扩展包配置为在 ChatGPT 页面上运行。未来版本可能调整平台支持范围；如果未来版本实质性改变数据处理方式或权限，本政策会在发布前更新。

## 2. ExportAI 处理的数据

当用户明确开始导出时，ExportAI 可能处理当前浏览器标签页中已经可读取的以下信息：

- 对话标题、消息角色、消息顺序和可读取的对话内容；
- 导出所需的结构信息，例如标题、列表、引用、代码、表格、公式、链接和可用的图片信息；
- 用于识别页面和生成导出元数据的当前页面 URL 或平台信息；
- 用于解析对话、生成预览以及生成 PDF、Markdown 或 JSON 文件的临时内存数据。

ExportAI 仅为提供用户请求的导出流程而处理这些信息，不会主动收集账户密码、Cookie、身份验证 Token，也不会主动读取隐藏、已删除或尚未加载到页面中的对话内容。

## 3. ExportAI 不收集的数据

当前版本的 ExportAI：

- 不要求 ExportAI 账户或登录；
- 不运行用于处理对话的 ExportAI 后端；
- 不向广告商或数据经纪商出售、出租或提供对话内容；
- 不使用分析、遥测、广告跟踪或错误上报服务；
- 不将对话文本、提示词、回答、代码或图片上传到 ExportAI 服务器；
- 不使用对话内容训练 AI 模型；
- 不提供云端存储、跨设备同步或在线对话库；
- 不会主动读取当前导出范围之外的其他标签页或无关页面内容。

## 4. 数据处理位置

对话解析、规范化、预览生成和文件生成均在浏览器中完成。ExportAI 在本地创建用户请求的文件，并交由 Chrome 发起下载，文件位置由用户或 Chrome 的下载设置管理。

当前版本不会将对话内容发送到 ExportAI 服务器，因此不会在 ExportAI 服务器保留对话副本。导出期间使用的临时浏览器内存数据会在流程结束或扩展页面关闭时释放，但仍受浏览器正常行为影响。

导出文件由用户控制，并可能包含用户选择导出的完整对话内容。Chrome 的下载设置、备份工具、同步功能、文件索引以及其他软件，可能在 ExportAI 创建文件后继续处理这些文件。用户应根据文件敏感程度采取适当保护措施。

## 5. 权限

ExportAI 请求 Chrome 的 `activeTab` 权限。用户开始导出时，该权限用于与当前标签页通信并读取当前标签页内容，以完成支持页面识别、可读取内容收集和本地文件生成。

当前发布清单没有额外请求 `downloads`、`storage` 或广泛的网站访问权限。Chrome 仍可能根据自身行为展示浏览器权限和扩展管理信息。

## 6. 第三方网站和内容

ExportAI 不隶属于 OpenAI、ChatGPT、Anthropic、Claude、Google、Gemini 或扩展界面及文档中提及的其他平台。ExportAI 只读取浏览器在支持页面上提供的内容，不绕过身份验证，不访问私有 API，也不恢复页面中不存在的内容。

用户应自行确认其有权导出、保存或分享对话及其中包含的第三方材料。导出对话不会改变原始平台的隐私条款、保留规则或安全措施。

## 7. 保留和删除

ExportAI 不维护在线账户，也不维护服务器端对话历史。用户可以通过操作系统或 Chrome 的常规文件管理功能删除本地生成的文件。如果未来版本引入新的数据流，本政策会在该数据流启用前更新，并说明相关保留和删除选项。

## 8. 安全

ExportAI 以减少数据移动和权限申请为设计目标。但任何浏览器扩展、浏览器、本地设备或文件系统都无法保证绝对安全。用户应及时更新 Chrome 和操作系统，检查扩展权限，并避免将敏感内容导出到自己无法控制的位置或服务。

## 9. 儿童隐私

ExportAI 是通用浏览器扩展，并非专门面向儿童，也不会明知故意收集儿童的个人信息。如果家长或监护人认为儿童在使用 ExportAI 时提供了个人信息，可以通过下方联系方式联系我们。

## 10. 政策变更

当 ExportAI 的数据实践、权限、支持平台或适用要求发生变化时，我们可能更新本政策。顶部的生效日期表示最新版本。对于重大变更，我们会在适当情况下通过产品公开页面或版本信息进行说明。
