# ExportAI PDF Fonts

## Noto Sans SC

- **Font**: Noto Sans Simplified Chinese (SC)
- **Source**: Google Fonts / Noto project
- **License**: SIL Open Font License 1.1
- **Purpose**: CJK (Chinese, Japanese, Korean) support for PDF generation
- **Weight**: Regular (400)

### License Summary

The SIL Open Font License (OFL) allows:
- Free use in commercial and non-commercial projects
- Redistribution with the software
- Modification (with name change requirement)

### Files

- `NotoSansSC-Regular.ttf` - Regular weight for body text
- `NotoSansSC-Bold.ttf` - Bold weight for headers and emphasis

### Download Source

Fonts can be downloaded from:
- https://fonts.google.com/noto/specimen/Noto+Sans+SC
- https://github.com/notofonts/noto-cjk
